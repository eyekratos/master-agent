# Master Agent

A personal AI-agent project designed to grow into a modular automation system.

## Planned capabilities

- A small API/backend for receiving tasks
- Modular tools and integrations
- Scheduled jobs
- Docker-based local development and deployment
- Cloud deployment when a suitable free hosting option is available

## Current status

Initial repository setup. Features will be added incrementally after the intended workflows and AI provider are selected.

## Development principles

- Keep secrets and API keys in environment variables; never commit them.
- Start with a minimal, testable service.
- Use free tiers where practical, while respecting provider limits.
- Add authentication before exposing private agent endpoints publicly.
